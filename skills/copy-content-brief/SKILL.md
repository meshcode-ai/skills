# Content Brief — The Delegation Document

A brief is not a summary; it is an **acceptance criteria sheet**. Without one, an editor sends it back three times; with one, once.

## The 10 Required Elements

1. **One reader** — role, situation, what they know / don't know
2. **One search intent** — no mixing informational/transactional/comparison; commit to one
3. **Primary keyword + secondary keywords** (placement rule: once in body, once in a heading)
4. **H2/H3 outline** — include all H2s from the top 3 competing pieces, then add 2 items they don't cover (the gap)
5. **Required facts/figures + source URLs** — so the writer can't improvise them
6. Length: allow within 15% of target. Length is a reference drawn from the competitive average, not the goal
7. Tone: 1–2 example sentences (what to say / what not to say)
8. **2 internal links + 1 external primary source**
9. One CTA — the next action this piece should drive
10. **Acceptance checklist** — approve or reject based on whether the elements above are met

## SERP Gap Analysis

Name the top 5's common omissions, contradictions, and stale figures as the brief's "must cover" list. This is where a brief earns its keep.

## Output

One brief document (10 elements marked) + a 3-line gap-analysis summary + writer notes flagging every spot that needs fact-checking. Quality standards are shared with `seo-content-eeat`.
