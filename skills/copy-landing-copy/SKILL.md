# Landing Page Copy

## The Hero Is the Verdict on the Whole Page

If it isn't readable in 5 seconds, there's no scroll. Lock the three hero elements: **① who it's for ② what they get (the outcome) ③ how (mechanism goes in the subheadline)**. Put a benefit, not a brand name, in the headline — "Code review automation for developers" > "Welcome to XX".

## Section Order (matching the conversion funnel)

1. Hero (outcome promised) → 2. Problem agitation (2–3 sentences, PAS-style) → 3. Solution (product screen + caption) → 4. How it works in 3 steps → 5. Proof (numbers, testimonials, logos) → 6. Objection handling (FAQ) → 7. CTA repeat

- Place proof right after the claim — the further back it goes, the weaker it gets.
- No feature lists; each feature needs a one-line benefit caption.
- Each section carries exactly one sentence — the one that earns the next scroll.

## Message Match

Repeat the promise language from ads and search results verbatim in the hero (keyword match; mismatch is the #1 cause of bounce). If you can't split the landing page per channel, treat the subheadline as the personalization line.

## CTA

- One primary CTA per screen, written like a headline ("Start free" > "Submit")
- Pair with friction-removal copy: "No card · 2-minute setup · cancel anytime"
- Top hero = soft action (demo, start); bottom = hard action (payment, contact).

## Output

3 hero options (headline + subheadline + CTA set) + a one-line-per-section outline + an ad-to-page keyword match table + 2 A/B candidate pairs.
