# Copy Editing — The Three-Pass Edit

Editing is not rewriting; it is **protecting the reader's time**. Break the order and you force a re-read, so never mix passes.

## Pass 1 — Structure (order of content)

- Does the first paragraph state the conclusion? (Inverted pyramid: conclusion → evidence → background)
- One paragraph = one topic. Two topics means split it.
- If you read only the headings, is the summary complete?
- A paragraph whose removal loses no meaning → delete it.

## Pass 2 — Sentences (within a single line)

- Max 40 words per sentence, one screen line. Split long sentences into two.
- Replace weak verbs: nominalized/passive constructions → a real verb ("a review is being requested" → "please review")
- Turn passive voice into active. Strip adverbs (very, really, truly) from verbs.
- No same word twice in a row, no 3rd repeat in one sentence. Keep tense and formality level consistent.
- Restore nominalized verbs (nominal -ing/-tion forms) back to verb form.

## Pass 3 — Final (notation)

- Consistent rules for numbers, units, abbreviations (Arabic numerals in prose; expand abbreviations on first use)
- Check special characters, consecutive spaces, zero-width characters, typos.
- Link text must describe the destination ("here" is banned).

## Defensive Checklist

[ ] Benefit in the first sentence [ ] One primary CTA [ ] Unverifiable superlatives deleted [ ] Reader stated explicitly [ ] Core three lines reachable on a 5-second scan

## Output

Per-pass change list (original → revised, one-line reason) + the full revised text + remaining judgment queries (tastes, spots needing fact-checks).
