# Offer Design

**Core deliverable**: a one-line offer statement. Template — "_[customer type]_ gets _[desired result]_ within _[timeframe]_ via _[unique mechanism]_, _[risk reversal]._"

**Value formula**: offer value = (benefit of the result × conviction) ÷ (price + time + effort + psychological friction). Raising the numerator (concrete numbers, evidence, guarantees) or lowering the denominator (easy start, risk removal) lifts conversion.

**Stack composition (required → optional)**: ① core deliverable (what is actually being sold) ② bonuses (ladders to the core — low variable cost, high margin) ③ guarantee / risk reversal (refund window, conditions stated clearly — unconditional refunds fine, but pair with anti-abuse wording) ④ scarcity / deadline (must be real — a fake deadline collapses brand trust) ⑤ social proof placement.

**Decision criteria**: the stack should feel worth 3–10× the core's value; beyond that it triggers suspicion. If a bonus cannibalizes the core, remove it. One offer = one result — two results means two segments, so split them (→ biz-segmentation). Align price-to-packaging with the same 3-point band framework used in biz-pricing-strategy.

## Output
3 candidate one-line offers, stack table (component, role, perceived value), guarantee terms wording, tier packaging (core + bonus combos), and the top 3 assumptions to validate.
